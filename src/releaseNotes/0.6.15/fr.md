### Nouveautés

- **La recherche du chat filtre par priorité**, pour que des questions comme « promotions urgentes » trouvent les bons e-mails.
- **Téléchargements signés** : les installateurs Windows sont signés et les paquets Linux sont accompagnés de sommes de contrôle signées.
- La version CUDA pour Windows vous prévient quand elle ne trouve pas CUDA, au lieu d'exécuter l'IA sur le CPU sans rien dire.
- Les **Smart Filters** écrivent leur requête dans la barre de recherche : clic pour chercher, clic droit pour l'ajouter à la recherche en cours, et **Afficher N de plus** dans les groupes longs.

### Confidentialité et sécurité

- Les serveurs Ollama situés sur une autre machine doivent utiliser HTTPS.
- Renforcement supplémentaire des versions Windows et Linux.

### Corrections

- Vous pouvez répondre depuis un autre compte que celui qui a reçu l'e-mail.
- Répondre à une note à vous-même remplit les destinataires.
- La vue **Tous les comptes** est plus rapide.
- Ajouter une catégorie Gmail télécharge les e-mails qu'elle contient déjà.
- Les notifications longues passent à la ligne au lieu d'être tronquées.
- Les résumés du chat lisent tout le fil, les liens du chat ouvrent l'e-mail visé, et un nouveau chat place le curseur dans la zone de saisie.
- Demander au chat les e-mails urgents n'affiche que des e-mails urgents.
