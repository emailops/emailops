Concepts & glossary

What is a KV-cache “anchor”?

The anchor is a never-evicted copy of the invariant system prefix tokens (the system message + tool definitions, the bytes every turn of every same-route conversation starts with). It lives on its own sequence (seq 2) so a brand-new conversation whose only commonality with the previous chat is the system block can reuse those tokens without a partial mid-sequence eviction — which hybrid-attention caches reject. When the new prompt diverges from the working prefix but still matches the anchor, the planner picks RestartFromAnchor: wipe seq 0, copy the anchor cells back into seq 0, decode only the divergent suffix.

What is the “generation header” / volatile tail?

Chat templates render a small header after the last message to cue the model to speak. Under Qwen 3 with enable_thinking=false that's literally <|im_start|>assistant\n<think>\n\n</think>\n\n. The next turn renders the same assistant slot as a history message — without the empty think block — so the header tokens that were "the most recent bytes" become stale and can't be partially evicted from hybrid-attention caches. We solve this by computing a stable boundary (the byte length of the render with add_generation_prompt=false), keeping everything up to it on seq 0, and decoding the volatile header tokens on seq 1 only — thrown away after generation.

How the cache is consulted (pseudo-code)

# actor.rs::generate_with_cache — runs on the persistent llama-inference thread
fn on_new_call(prompt, cached, cached_system):
    tokens          = tokenize(prompt)             # BOS + chat template
    stable_tok      = stable_boundary(tokens)      # excludes the gen header
    sys_tok         = system_prefix_tokens(tokens) # invariant leading bytes

    # ── 1. Decide the seq-0 plan (no partial mid-seq evictions allowed) ──
    lcp_seq0   = longest_common_prefix(cached,        tokens)
    lcp_anchor = longest_common_prefix(cached_system, tokens)
    plan = match (lcp_seq0, lcp_anchor):
        lcp_seq0   == cached.len()        → Extend{reuse = lcp_seq0}      # pure suffix-append
        lcp_anchor == cached_system.len() → RestartFromAnchor{reuse}  # new convo, system matches
        _                                 → ColdPrefill                # wipe everything

    # ── 2. Apply the plan to the real KV ──
    match plan:
        Extend            : # keep seq 0 as-is; lcp = reuse
        RestartFromAnchor : clear(seq=0); copy_kv(anchor → seq=0, len=reuse)
        ColdPrefill       : clear(seq=0); clear(seq=2); cached_system = []  # anchor wiped here ←

    # ── 3. Decode the divergent suffix on seq 0 (becomes new cache) ──
    decode(tokens[lcp .. stable_tok], seq=0)
    cached = tokens[0 .. stable_tok]

    # ── 4. Re-seed the anchor when the system prefix changed ──
    if sys_tok > 0 and cached_system != tokens[0 .. sys_tok]:
        clear(seq=2); copy_kv(seq=0 → anchor, len=sys_tok)
        cached_system = tokens[0 .. sys_tok]

    # ── 5. Volatile gen header + generation on seq 1 only ──
    copy_kv(seq=0 → seq=1)                          # cells shared via tagging, no copy cost
    decode(tokens[stable_tok .. end], seq=1)    # gen header — thrown away next call
    output = sample_loop(seq=1)

# For aux one-shots (cache_prompt=false):
fn on_aux_call(prompt, cached):
    if aux_prompt + reserve fits beside cached:
        decode(prompt, seq=1); generate(seq=1)     # seq 0 untouched
    else:
        clear_all(); cached = []; cached_system = []  # sacrifice resident
        decode(prompt, seq=1); generate(seq=1)

Badges in the timeline

🌳 Anchor hit
Fires when the actor picked RestartFromAnchor: the new prompt diverged from seq 0 (so it can't Extend) but its leading tokens still match the system anchor on seq 2. The actor wipes seq 0, copies the anchor cells back into seq 0 (free — same cells, just retagged), and decodes only the divergent suffix. The textbook good case for a brand-new conversation on the same route as the previous one — you save the entire system-prefix prefill (the slowest part of any LLM call on M1 / CPU).
🌱 Fresh
First cached call after the cache was empty or just wiped. Nothing to reuse; full prefill happens. Expected for the very first chat after a model load, or right after a ColdPrefill.
🪴 Grown
Within-conversation Extend: the new prompt is a strict suffix-append of the resident seq 0 (lcp == cached.len()). Reuses ~95% — only the newly-appended tail (the next turn, or the tool result added between rounds) gets decoded.
🔥 Wiped & reseeded
ColdPrefill that took out a populated anchor. Happens on a route flip (rag↔tools changes the system message bytes) or any other system-message change. The previous anchor is invalid, so the actor clears it before re-prefilling seq 0, then seeds a fresh anchor from the new system prefix.
❄️ Evicted resident
An aux cache_prompt=false call (large rerank, lens extraction, etc.) couldn't fit beside the resident chat prefix in the cell budget, so the actor sacrificed seq 0 to make room. The next chat turn cold-prefills from scratch — visible as a cold call right after the aux row.
· Passthrough
Aux call that ran entirely on seq 1 without evicting. The resident chat prefix is untouched — the next chat turn can still Extend or anchor-hit.

All terms

cached LCP (reused, free) decoded on seq 0 (new cache) volatile tail on seq 1 (thrown away) seq 2 anchor (system prefix) uncached aux (one-shot on seq 1)
