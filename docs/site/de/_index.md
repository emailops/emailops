title: 'Dokumentation'
description: 'Alles, was Sie brauchen, um EmailOps zu installieren, einzurichten und optimal zu nutzen — der E-Mail-Client, der die KI auf Ihrer eigenen Maschine ausführt.'
---

EmailOps ist ein Desktop-E-Mail-Client mit eingebauter lokaler KI. Er synchronisiert Ihre
Gmail-, Outlook- und IMAP-Konten in eine Datenbank auf Ihrer eigenen Maschine und führt die
KI-Funktionen — Chat, Antwortentwürfe, Klassifizierung, semantische Suche — auf dieser lokalen
Kopie aus. Standardmäßig wird nichts an einen Server gesendet: Das Modell läuft in der App.

EmailOps ist kostenlos und Open Source (Apache-2.0). Der Quellcode liegt auf
[github.com/emailops/emailops](https://github.com/emailops/emailops).
