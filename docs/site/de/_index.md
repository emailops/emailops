<!-- claim:index-intro-1 -->
EmailOps ist ein E-Mail-Client mit eingebauter lokaler KI. Er synchronisiert Ihre
Gmail-, Outlook- und IMAP-Konten in eine Datenbank auf Ihrer eigenen Maschine und führt die
KI-Funktionen — Chat, Antwortentwürfe, Klassifizierung, semantische Suche, Übersetzung — auf
dieser lokalen Kopie aus. Standardmäßig wird nichts an einen Server gesendet: Das Modell läuft
in der App.

<!-- claim:index-intro-2 -->
EmailOps ist kostenlos und Open Source (Apache-2.0). Der Quellcode liegt auf
[github.com/emailops/emailops](https://github.com/emailops/emailops).
