title: 'Documentation'
description: "Tout ce qu'il faut pour installer, configurer et tirer parti d'EmailOps — le client e-mail qui exécute l'IA sur votre propre machine."
---

EmailOps est un client e-mail avec IA locale intégrée. Il synchronise vos comptes
Gmail, Outlook et IMAP dans une base de données sur votre propre machine, et exécute les
fonctions d'IA — chat, brouillons de réponse, classification, recherche sémantique, traduction —
sur cette copie locale. Par défaut, rien n'est envoyé à un serveur : le modèle s'exécute dans
l'application.

EmailOps est gratuit et open source (Apache-2.0). Le code source se trouve sur
[github.com/emailops/emailops](https://github.com/emailops/emailops).
